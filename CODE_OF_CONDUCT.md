# Community code of conduct

We want this project to be a useful, technically rigorous, and welcoming place to improve agent safety.

Be respectful, discuss evidence and designs rather than people, make room for different experience levels, and avoid harassment, threats, discriminatory language, deliberate disruption, or publication of another person's private information.

Security disagreements should be handled with care. Do not pressure reporters to publish exploit details before a fix is available, and do not use real credentials or private data in demonstrations.

Project maintainers may edit or remove abusive or unsafe contributions and may temporarily or permanently restrict participation. Report conduct concerns privately through the repository owner's GitHub profile. Reports will be handled as confidentially as practical.
